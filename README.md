# Лист героя

Листы персонажей для настольных ролевых игр — D&D 5e (2014 и 2024), GURPS 4e и Манчкин — с выдвижной справкой по каждому полю, автоподсчётом и справочниками со страницами книг.

**Открыть:** https://anton-onskul.github.io/rpg-for-me/

- Персонажи хранятся в браузере устройства; переносить между устройствами — кнопками «Выгрузить» / «Загрузить файл».
- PDF книг каждый игрок выбирает у себя: файл остаётся на его устройстве и никуда не загружается.

## Разработка

```
npm ci
npx playwright install chromium
npm test        # тесты логики и тесты интерфейса в браузере
npm run build   # собирает dist/index.html
```

Каждое изменение в `main` проверяется тестами в GitHub Actions; сайт обновляется, только если все тесты прошли.

- `src/core.js` — расчёты и хранение (без браузера, покрыто тестами)
- `src/help.js` — тексты справки
- `src/dnd5e-data.js`, `src/gurps-data.js` — классы, происхождения, предыстории, справочник GURPS
- `src/app.html` — интерфейс; `build.js` собирает всё в один файл `dist/index.html`


## Тестовая HTTPS-версия через Cloudflare Pages

**Основной сайт на GitHub Pages не меняется.** Для проверки WebRTC на ПК и телефоне
используйте отдельный Cloudflare Pages-проект, подключённый к этому репозиторию.

### Подключение (один раз)

1. Откройте [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** →
   **Create** → **Pages** → **Connect to Git** (названия пунктов могут отличаться).
2. Авторизуйте GitHub и выберите `Anton-Onskul/rpg-for-me`.
3. Укажите уникальное имя проекта, например `rpg-for-me-test-onskul`. Имя определяет адрес
   `https://<имя>.pages.dev`; **адрес существует только после успешного развёртывания**.
4. В качестве **Production branch** выберите `preview/cloudflare-pages-pr2`
   (НЕ `main` и НЕ ветку основного сайта).
5. Настройки сборки: **Framework preset** — `None`; **Build command** —
   `npm ci && npm run build && npm run test:preview`; **Build output directory** —
   `dist`; **Root directory** — корень репозитория; **Node.js** — версия `22`
   (при необходимости задайте переменную окружения `NODE_VERSION=22`).
6. Нажмите **Save and Deploy** и дождитесь успешного статуса. Откройте выданный
   Cloudflare HTTPS-адрес на компьютере и телефоне.

При выборе существующего Cloudflare-проекта **не переключайте его production branch**,
если проект уже обслуживает другой сайт. Создайте отдельный проект.

### Как проверить связь

1. Откройте один и тот же Cloudflare URL на ПК и телефоне (не `localhost`).
2. На ПК создайте стол мастера и включите доступ по интернету. На телефоне
   выберите вход игрока и введите код. Проверьте обмен изменениями карты.
3. Поменяйте роли: мастер на телефоне, игрок на ПК.
4. Повторите оба сценария через одну Wi-Fi сеть и через мобильный интернет.
5. При ошибке на обоих устройствах откройте «Проверить связь» и сохраните отчёты.

**Ограничение:** тестовая публикация обеспечивает HTTPS, но не предоставляет TURN.
В `src/table-ui.js` переменная `TURN_URL` пока пустая. Если мобильная сеть
блокирует прямое WebRTC-соединение, потребуется отдельная настройка TURN.
Cloudflare Pages сам по себе эту проблему не решает.

### Проверка сборки перед публикацией

```bash
npm ci
npm run build
npm run test:preview
npm test
```

`test:preview` проверяет наличие готового `dist/index.html`, встраивание
сетевого кода и отсутствие незаменённых маркеров сборки. Полные тесты запускаются
через `npm test` и GitHub Actions. Тестирование на двух устройствах остаётся обязательным.
