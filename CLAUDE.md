# Правила работы над rpg-for-me

Обязательны для всех чатов проекта (часть для игроков, часть для мастера и любые новые).

## Порядок работы над любой задачей

1. **Уточняющие вопросы.** Прежде чем что-то делать, задать вопросы и дождаться ответов. Не додумывать за пользователя.
2. **План и спецификация.** Составить и показать:
   - план: шаги, что за чем делается;
   - спецификацию: что должно работать, входные и выходные данные, поведение на экранах, граничные случаи, что в задачу НЕ входит.
3. **Тесты до кода (TDD).**
   - Написать тесты, которые проверяют спецификацию и показывают, где код ломается.
   - Запустить и показать, что они проваливаются.
   - Написать код, который их проходит.
   - Если тесты не проходят — исправлять код, пока не пройдут. Тесты не ослаблять, чтобы «позеленело».
4. **Итог.** Коротко: что сделано, результат прогона тестов, что осталось.

## Общие решения по проекту

- Веб-приложение (телефон и ПК), публикация через GitHub Pages: https://anton-onskul.github.io/rpg-for-me/
- Тесты прогоняются автоматически при каждом изменении (`.github/workflows/ci.yml`). Сайт обновляется, только если все тесты прошли.
- Перед коммитом локально: `npm test` и `npm run build`.
- Работа поделена по чатам: часть 1 — всё для игроков (лист героя); часть для мастера (стол мастера) — отдельный чат. Каждый чат трогает только свою часть.

## Стиль общения

- Работать быстро, отвечать конкретно.
