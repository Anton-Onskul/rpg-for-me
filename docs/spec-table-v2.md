# Стол: доработки после проверки (ноябрь 2026)

## План
1. Тесты логики (`tests/table-v2.test.js`) и экрана (`tests/table-v2.e2e.test.js`) — до кода, прогон показывает провал.
2. Логика стола (`src/table.js`): эффекты, правка своих хитов игроком, туман по обзору.
3. Подсказки (`src/tips.js`): новые, поведение «по вкладке».
4. Экран (`src/table-ui.js`): кнопка «Свернуть», «Двигать» у игрока, карточка героя, полоса очереди, сворачивание характеристик, туман по обзору, полоски в бою.
5. Полный прогон тестов, скриншоты ПК/телефон, публикация. Сетевую часть (`src/net.js`) не трогаю — она в другом чате.

## Спецификация

### 1. Ошибки
- «Свернуть» в «С чего начать» закрывает список — мышью и касанием на телефоне.
- Подсказка вкладки показывается при **каждом** заходе на вкладку, пока не нажали «Понятно». Ушли с вкладки — её подсказка прячется и не считается увиденной.
- Цепочка только внутри одного места (например, при открытии стола), между вкладками — нет.
- «Показать подсказки заново» — показывается только подсказка текущей вкладки.

### 2. Игрок двигает фишку
- У игрока на панели карты кнопка «Двигать» рядом с «Линейкой». Двигает только свою фишку, свободно.

### 3. Новые подсказки
- «Как отдать героя игроку» (при выборе фишки: поле «Управляет»), «Туман по обзору», «Эффекты в бою», «Двигать» у игрока, «Ваша карточка героя».

### 4. Карточка героя игрока (справа снизу)
- Видна игроку, если у него есть фишка на активной сцене. Данные: имя и лист, который он отправил, плюс поля фишки.
- D&D: хиты, КД, скорость, пасс. внимательность; GURPS: ЕЖ, Уклонение, Движение, Баз. скорость; Манчкин: уровень, сила в бою. Плюс эффекты на герое.
- Игрок сам меняет свои хиты (в Манчкине — уровень и бонус). Остальное меняет только мастер.
- В свой ход на карточке — крупная кнопка «Завершить ход».
- Полоса очереди ходов над картой (игроку и мастеру): раунд, участники по порядку, текущий выделен. Ход скрытого существа — «ходит кто-то невидимый».

### 5. Фишки у мастера
- Характеристики выбранной фишки сворачиваются (блок «Характеристики»); выбор «свёрнуто» запоминается при переключении фишек.

### 6. Туман по обзору
- В «Сценах» режим тумана: «Вручную» (как сейчас) или «По обзору героев».
- Радиус обзора — на сцену (в футах/ярдах/клетках по НРИ), у фишки можно задать свой (например, тёмное зрение 60 фт).
- Обзор общий для всех героев (фишки типа «герой»). Видимая клетка — центр в пределах радиуса от героя (круг, стен пока нет).
- Где герой был — «исследовано»: у игроков полупрозрачный туман, монстров там не видно. Где не был — полный туман. Видно сейчас — без тумана.
- Мастер видит всё; ручные «Открыть/Скрыть» продолжают работать («Скрыть» стирает и исследованное).

### 7. Бой у мастера: полоски и таблички
- Во вкладке «Бой» у каждого участника: полоска хитов (цвет по состоянию), главные поля системы, эффекты-значки с оставшимися раундами.
- Эффекты: готовый список по НРИ + свой текст, длительность в раундах (или без срока). В начале каждого нового раунда срок уменьшается; на нуле эффект снимается, в чат пишется «закончилось». Добавляет и снимает мастер.
- Игроки видят названия эффектов на видимых существах и на своём герое.

### Не входит
- Стены и двери для обзора, ограничение движения скоростью, отдельный обзор каждого игрока.
