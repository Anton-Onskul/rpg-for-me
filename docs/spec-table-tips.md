# Подсказки за столом (мастер и игрок)

## План
1. Модуль `src/tips.js` — список подсказок, выбор следующей, чек-лист «С чего начать», хранение «уже видел / выключено».
2. Тесты: `tests/tips.test.js` (логика) и `tests/tips.e2e.test.js` (экран) — пишутся до кода, прогон показывает провал.
3. Встраивание в `src/table-ui.js`: всплывающее окно подсказки, кнопка «Подсказки», чек-лист мастера.
4. Прогон всех тестов, проверка скриншотов (ПК и телефон), публикация.

## Спецификация

### Всплывающие подсказки «как в играх»
- Небольшая карточка (заголовок, 1–3 предложения, кнопки «Понятно» и «Выключить подсказки») со стрелкой к элементу, о котором речь.
- Появляется сама, когда человек впервые попадает в место: открыл стол, вкладку (Сцены, Фишки, Бой, Журнал, Игроки, Мой герой), инструмент (Открыть, Скрыть, Линейка), выбрал фишку, начал бой, нажал на поле броска, подключился первый игрок, наступил ход игрока.
- Каждая подсказка показывается один раз; «Понятно» — больше не показывать её.
- Одновременно видна только одна подсказка. Окно без затемнения: карта и кнопки остаются рабочими.
- Не закрывает основную часть экрана: не перекрывает центр карты, занимает не больше ~15% окна на ПК; на телефоне — полоса внизу не выше 40% экрана.
- Если элемента сейчас нет на экране — подсказка не показывается (дождётся).
- Учитывает НРИ стола: кубики (D&D — преимущество/помеха; GURPS — 3к6 под навык; Манчкин — к6), поля фишек (Хиты/КД; ЕЖ/СП/Уклонение/Движение; Уровень/Бонус), инициатива, линейка (футы/ярды/клетки).
- Свои наборы для мастера и для игрока.

### Чек-лист «С чего начать» (только мастер)
- Кнопка в верхней панели: «С чего начать · N/7». По нажатию — список шагов с галочками в правом верхнем углу карты (не закрывает кубики, чат и центр карты):
  1. Создать сцену; 2. Загрузить карту; 3. Добавить фишки; 4. Открыть часть карты в тумане; 5. Позвать игроков; 6. Отдать фишку игроку; 7. Начать бой.
- Галочки ставятся сами по состоянию стола. Нажатие на шаг — переход на нужную вкладку.
- При первом открытии стола на ПК список открыт; потом закрыт. На телефоне сам не раскрывается (закрыл бы карту) — на кнопку указывает подсказка. Когда все 7 готовы — кнопка «Готово ✓».

### Включение и выключение
- Кнопка «Подсказки: вкл/выкл» в верхней панели, выбор запоминается на устройстве (`localStorage`, ключ `rpg-table.tips`).
- В чек-листе — «Показать подсказки заново» (сбрасывает «уже видел»).
- Если хранилище браузера недоступно — работает в памяти, без ошибок.

### Не входит
- Подсказки в листах персонажей (часть для игроков), видео, обучение правилам НРИ целиком.
